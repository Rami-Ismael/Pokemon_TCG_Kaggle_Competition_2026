# Experiment cards

One file per experiment, named `<date>-<slug>.md`, written **before** the run
starts. The card template and the rules for filling it live in the
`idea-to-experiment` skill (`.claude/skills/idea-to-experiment/SKILL.md`).

Cards are append-only history: negative and inconclusive results stay here —
they are the record of what we already tried and why we stopped.
